## 2. 시스템 목적

품질설계결과 에러현황 조회 화면은 품질설계 처리 과정에서 발생한 에러 이력을 조회하는 기능을 제공한다. 주문번호, 주문행번 및 품질설계 에러 발생 일자 범위를 기준으로 에러 데이터를 검색하여 현황을 파악할 수 있다.

업무 담당자는 이 화면을 통해 특정 주문의 품질설계 에러 코드, 에러 내용, 해결방법, 에러 발생일 등의 정보를 확인할 수 있다. 또한 반송 데이터를 제외하는 옵션을 제공하여 실질적인 에러 현황만을 파악하는 데 활용한다.

조회된 에러 목록에서 특정 항목을 선택하면 해당 주문의 품질설계 상세 화면(C104000020)으로 이동하여 더 자세한 내용을 확인할 수 있으며, 팝업 또는 탭 형태로 호출될 수 있다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 품질설계 에러현황 조회</summary>

- **Actor**: 품질 담당자
- **목적**: 주문 또는 기간 조건으로 품질설계 에러 발생 이력을 조회하여 현황을 파악한다
- **주요 흐름**:
  1. 조회 조건(주문번호/주문행번 또는 에러 발생 일자 범위)을 입력한다
  2. 반송 건 포함/제외 여부를 선택한다
  3. 조건에 해당하는 에러 목록(에러 코드, 에러 내용, 해결방법, 발생일)이 표시된다
- **예외**: 날짜 형식이 올바르지 않으면 조회가 수행되지 않는다

</details>

<details>
<summary>UC-02: 품질설계 에러 상세 조회</summary>

- **Actor**: 품질 담당자
- **목적**: 에러 목록에서 특정 주문의 품질설계 상세 정보를 확인한다
- **주요 흐름**:
  1. 에러현황 목록에서 확인할 항목을 선택한다
  2. 해당 주문의 품질설계 상세 화면(C104000020)이 새 탭으로 열린다
  3. 상세 화면에서 품질설계 전체 정보를 조회한다

</details>

<details>
<summary>UC-03: 반송 제외 에러현황 조회</summary>

- **Actor**: 품질 담당자
- **목적**: 반송 건을 제외한 실질적인 품질설계 에러 현황만 파악한다
- **주요 흐름**:
  1. 반송제외 체크박스를 활성화한 상태로 조회 조건을 입력한다(기본값: 반송 제외)
  2. 반송 유형이 제외된 에러 목록이 조회된다
  3. 순수 품질설계 오류에 해당하는 건만 확인하여 현황을 분석한다

</details>

### 엔티티 간 관계
- TB_C10_QLT_DSN_ERR는 품질설계 에러 발생 이력을 주문번호/주문행번 기준으로 관리한다
- M00APUSER.VI_M00_CODE_ACCESS는 TB_C10_QLT_DSN_ERR의 에러 코드에 대응하는 코드명을 제공한다
- MESAPUSER.VI_MES_TRM_CTL은 반송 유형 여부 판단에 참조되어 조회 결과 필터링에 사용된다

## 11. 특이사항 및 주의사항

### 1. 조회 전용 서비스
이 서비스는 데이터 저장, 수정, 삭제 기능이 없는 순수 조회 전용 서비스이다. 모든 그리드 컬럼이 읽기 전용(ro)으로 설정되어 있어 데이터 변경이 불가능하다.

### 2. 반송 제외 기본값 처리
반송제외(ORD_BAK_SND_TP) 필터는 화면 초기 진입 시 체크박스가 기본으로 활성화된 상태로 표시된다. 이에 따라 기본 조회 시 반송 유형에 해당하는 에러 건은 자동으로 제외되며, 담당자가 필요에 따라 포함하도록 선택할 수 있다.

### 3. 자동 조회 조건
화면 로드 시 주문번호와 주문행번이 파라미터로 전달된 경우, 또는 날짜 조건이 설정된 경우 자동으로 조회가 수행된다. 이 화면은 C104000020(품질설계 상세) 등 다른 화면에서 팝업 또는 탭으로 호출될 수 있으며, 호출 시 주문 정보가 전달되어 해당 주문의 에러 현황이 즉시 표시된다.

### 4. 상세 화면 연계
에러현황 목록에서 행을 더블클릭하면 해당 주문번호와 주문행번을 파라미터로 하여 C104000020 품질설계 상세 화면이 새 탭으로 열린다. 에러 현황 조회와 품질설계 상세 내용 확인이 연계된 업무 흐름을 지원한다.
