## 2. 시스템 목적

C107000020 업무기준조회 화면은 C10 모듈(컬러 강판 생산 공정)에서 운용되는 각종 업무 기준 데이터를 탭 형식으로 일괄 조회하기 위한 참조 화면이다. 생산 계획 담당자 및 품질 관리 담당자가 활용하며, 규격·사양·공정·도금·인쇄 롤 등 14개 업무 영역의 마스터 기준을 단일 화면에서 확인할 수 있도록 지원한다.

각 탭은 M00APUSER(마스터 데이터) 스키마의 범용 모델 정의 테이블에서 업무 영역별로 정의된 기준 데이터를 조회하여 표시한다. 화면에서 데이터 변경은 수행하지 않으며, 검색 조건 입력 후 해당 기준 목록을 조회하는 읽기 전용 기능만 제공한다.

이 화면은 수주 처리, 제조 지시, 품질 검사 등 C10 모듈 내 다른 업무에서 참조 기준으로 활용되는 데이터를 사전에 확인하는 목적으로 사용된다.

## 9. 관련 엔티티

### 엔티티 목록

| 엔티티(테이블) | 설명 | 사용 유형 |
|---------------|------|----------|
| M00APUSER.TB_M00_DATAS010 | 범용 모델 데이터 저장소 — 업무 영역별 기준 데이터(규격, 사양, 공정, 도금, 롤 등)를 구조화하여 보관 | 조회 |
| M00APUSER.TB_M00_DEFINES010 | 범용 모델 정의 테이블 — 업무 영역(MDL_DEFINE_NM)별로 데이터 스키마를 정의하며 활성 기간 관리 | 조회 |

### 엔티티 간 관계

- TB_M00_DEFINES010은 업무 영역별 모델 정의(MDL_DEFINE_NM: C10A1010, C10A1020 등)를 보유하며, 활성 기간(START_ACTIVE_DATE ~ END_ACTIVE_DATE) 내 유효한 정의를 제공한다
- TB_M00_DATAS010은 TB_M00_DEFINES010의 MDL_DEFINE_ID를 외래키(MD_MRG_BAS_ID)로 참조하여, 정의된 모델에 속하는 실제 기준 데이터를 저장한다
- 각 탭은 서로 다른 MDL_DEFINE_NM(C10A1010~C10A2182)으로 TB_M00_DEFINES010을 필터링한 후 연결된 TB_M00_DATAS010 데이터를 조회한다

## 11. 특이사항 및 주의사항

### 1. 범용 모델 테이블 기반 다중 업무 기준 관리
모든 탭이 동일한 물리 테이블(TB_M00_DATAS010 / TB_M00_DEFINES010)을 사용하되, MDL_DEFINE_NM 값으로 업무 영역을 구분한다. 14개 탭이 각기 다른 모델 정의명(C10A1010, C10A1020, C10A1022, C10A1023, C10A1054, C10A1061, C10A1070, C10A1079, C10A1091, C10A1092, C10A2030, C10A2040, C10A2181, C10A2182)을 사용하며, 모든 데이터는 범용 컬럼(MD_MRG_BAS_KEY_CHAR_TP_N, MD_MRG_BAS_DATA_CHAR_TP_N, MD_MRG_BAS_DATA_NUM_TP_N)에 저장된다.

### 2. 기준 데이터 유효 기간 관리
TB_M00_DEFINES010의 START_ACTIVE_DATE와 END_ACTIVE_DATE로 업무 기준 정의의 활성 기간을 관리한다. SYSDATE 기준으로 활성 기간 내 정의만 조회에 참여하므로, 과거 또는 미래 기준 버전은 자동으로 제외된다. 기준 변경 시 이력 보관이 가능한 구조이다.

### 3. 순수 조회 전용 화면 — 데이터 변경 기능 없음
메인 서비스(C107000020-service.xml)는 initial="end"로 설정되어 있어 어떤 활동도 수행하지 않는다. 14개 탭 서비스 모두 FormSearch(단순 조회) Activity만 포함하며, INSERT/UPDATE/DELETE 로직이 전혀 없다. 업무 기준 데이터의 등록·수정은 M00 마스터 모듈에서 별도 관리한다.

### 4. 탭14(고객사양길이공차기준) 추가 구성
서비스 구성 명세에서 tab14까지 포함됨을 확인하였다(tab14-service.xml, tab14-query.glue_sql 존재). 고객사양폭공차기준(tab13)과 동일한 구조로, 주문 길이 관리 코드별 길이 공차 하한/상한을 제공하며 수주 시 길이 허용 범위 확인에 사용된다.
