# BPA 생성 체크리스트

## 개요
- **목적**: generate-bpa 스킬 실행 대상 서비스 목록 관리
- **범위**: C10 모듈 주요 서비스 (UI 화면 기준)
- **제외**: tab/pop 접미사 서비스, 유틸리티/프레임워크 서비스, 다른 모듈 서비스

## 통계
- **총 부모 서비스 수**: 93
- **NUI/배치 프로세스**: 16
- **UI 화면 서비스**: 77

## 사용 방법
1. 각 서비스별로 `/generate-bpa SERVICE-ID` 명령 실행
2. 완료 후 해당 행의 상태를 ☑️로 변경
3. 전체 체크리스트 진행률 확인

## 참고사항

- **tab/pop 표기**: (tab12 pop7) = 탭 12개, 팝업 7개 포함
- **Memory 규칙**: 체크리스트 마킹 시 그룹 번호를 포함하여 표기 (예: ☑️ 6-1 등)
- **서비스 ID 패턴**:
  - C10X: UI 화면 서비스 (X=대분류)
  - B10R: 배치/NUI 프로세스
  - B10S: 스케줄러 작업
