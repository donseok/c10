## 2. 시스템 목적

반복주문자동설계 조회 화면은 품질설계가 완료된 반복주문 목록을 조회하는 기능을 제공한다. 품질 담당자 및 주문 담당자가 설계완료일자, 고객사, 품명, 등록자, 주문번호 등 다양한 조건으로 자동설계된 반복주문 건을 검색하고 그 결과를 확인할 수 있다.

이 화면은 반복주문번호가 존재하고 품질설계 승인 상태(설계확정구분 'A', 설계상태코드 'A')인 주문에 대해서만 데이터를 표시한다. 조회 결과에서 주문번호 또는 반복주문번호를 클릭하면 C104000020 화면(품질설계 상세)으로 이동하여 해당 주문의 상세 설계 정보를 확인할 수 있다.

조회 조건의 고객사 콤보박스는 입력된 날짜 범위에 따라 동적으로 갱신되어, 해당 기간 내 반복주문이 존재하는 고객사만 선택 목록에 표시된다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 설계완료일자 범위로 반복주문자동설계 목록 조회</summary>

- **Actor**: 품질 담당자 / 주문 담당자
- **목적**: 지정된 설계완료일자 범위 내에서 자동설계 완료된 반복주문 목록을 확인
- **주요 흐름**:
  1. 설계완료일자 시작/종료를 입력한다 (기본값: 오늘 기준 -30일 ~ 오늘)
  2. 고객사, 품명, 등록자 조건을 선택/입력한다 (선택 사항)
  3. 조회를 실행하면 품질설계 승인 상태의 반복주문 목록이 표시된다
  4. 주문번호 또는 반복주문번호 링크를 클릭하면 C104000020 상세화면으로 이동한다
- **예외**: 설계완료일자 미입력 또는 날짜 범위 오류 시 조회가 실행되지 않고 오류 메시지가 표시됨

</details>

<details>
<summary>UC-02: 특정 주문번호로 반복주문자동설계 조회</summary>

- **Actor**: 품질 담당자 / 주문 담당자
- **목적**: 주문번호와 행번으로 특정 주문의 자동설계 결과를 직접 검색
- **주요 흐름**:
  1. 주문번호와 행번을 입력한다
  2. 조회를 실행하면 해당 주문번호 기준으로 별도 쿼리가 실행된다
  3. 등록자명을 기준으로 필터링된 반복주문 목록이 표시된다
- **예외**: 주문번호 입력 시 일반 조회와 다른 경로(주문번호로찾기)로 서버 요청이 분기됨

</details>

<details>
<summary>UC-03: 고객사 콤보 동적 조회</summary>

- **Actor**: 품질 담당자 / 주문 담당자
- **목적**: 설계완료일자 범위에 따라 해당 기간의 반복주문이 존재하는 고객사 목록만 선택 가능하도록 콤보 갱신
- **주요 흐름**:
  1. 화면 로드 또는 설계완료일자 변경 시 고객사 콤보 목록이 자동으로 재조회된다
  2. 해당 날짜 범위 내 품질설계 승인 상태(ORD_REP_YN='X', QLT_DSN_CFM_TP='A', QLT_DSN_STS_CD='A')의 반복주문에 포함된 고객사만 목록에 표시된다
  3. '전체' 항목이 목록 최상단에 포함된다
- **예외**: 해당 기간에 반복주문이 없으면 '전체' 항목만 표시됨

</details>

### 엔티티 간 관계

- TB_C10_QLT_DSN_CMN은 조회의 주 데이터 원천으로, 품질설계 승인 완료(QLT_DSN_CFM_TP='A', QLT_DSN_STS_CD='A')이고 반복주문번호(ORD_REP_NO)가 존재하는 레코드만 대상으로 한다
- VI_M00_CODE_ACCESS는 TB_C10_QLT_DSN_CMN의 코드값(품명코드, 제품형태, 유통경로, 주문종류, 고객사코드)을 표시용 명칭으로 변환하는 데 사용된다
- TB_M90_EMP_INF는 TB_C10_QLT_DSN_CMN의 등록자 사번(ORD_RGS_PRS_ID)을 사원명으로 변환하거나, 등록자명으로 주문 검색 시 사번 역조회에 사용된다

## 11. 특이사항 및 주의사항

### 1. 조회 조건에 따른 서버 요청 분기 처리

조회 버튼 실행 시 주문번호 입력 여부에 따라 서버로의 요청 경로가 달라진다. 주문번호 미입력 시 일반 날짜/고객사/품명 조건으로 `조회` 액티비티를 호출하고, 주문번호 입력 시 `주문번호로찾기` 액티비티를 호출한다. 두 경로는 서로 다른 SQL 쿼리와 파라미터 구성을 사용하므로 결과 집합의 필터 방식이 다르다.

### 2. 고객사 콤보의 동적 갱신

고객사 콤보는 날짜 범위가 변경될 때마다 서버에서 재조회된다. 날짜 범위 내에서 품질설계 승인 상태의 반복주문이 존재하는 고객사만 콤보에 표시되므로, 날짜 조건을 변경하면 선택 가능한 고객사 목록이 달라진다. 콤보 데이터는 `OrdlnComboData.do`를 통해 별도 요청으로 로드되며 결과는 XML 형식으로 반환된다.

### 3. 반복주문 필터 조건

이 화면은 품질설계 공통 테이블(TB_C10_QLT_DSN_CMN) 전체가 아닌, 반복주문번호(ORD_REP_NO)가 존재하고 ORD_REP_YN='X', 설계확정구분(QLT_DSN_CFM_TP)='A', 설계상태코드(QLT_DSN_STS_CD)='A' 조건을 동시에 만족하는 데이터만 표시한다. 즉, 자동설계가 완료 승인된 반복주문만을 대상으로 한다.

### 4. 주문번호·반복주문번호 링크를 통한 상세 화면 연계

그리드의 주문번호 컬럼과 반복주문번호 컬럼은 링크 타입(ahref_idx)으로 설정되어 있으며, 클릭 시 C104000020 화면(품질설계 상세)으로 이동한다. 주문번호 클릭 시 ORD_NO·ORD_LN, 반복주문번호 클릭 시 ORD_REP_NO·ORD_REP_LN이 파라미터로 전달된다.
