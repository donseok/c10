## 2. 시스템 목적

디지털프린트 작업지시 조회 화면은 컬러강판 도장라인(A5 공정)에서 디지털프린트 작업이 예정된 코일(BOM)의 작업지시 현황을 실시간으로 파악하기 위한 조회 전용 시스템이다. 작업 담당자는 작업 예정일자 범위와 BOM번호·MO번호 조건으로 대상 코일을 검색하고, 각 코일의 제품 사양(두께, 폭, 품명, SubClass)과 작업 예정 일시를 한눈에 확인할 수 있다.

코일 목록에서 특정 항목을 선택하면 해당 코일의 디지털프린트 이미지, 품질 메시지, 도장 설계 정보(고객사·용도·도막 색상·보호필름 등), 최근 생산완료 이력이 화면 우측에 즉시 표시된다. 이를 통해 작업 준비 단계에서 도장 사양과 품질 기준을 신속하게 확인하고 올바른 작업 설정을 지원한다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 디지털프린트 작업지시 목록 조회</summary>

- **Actor**: 도장라인 작업 담당자
- **목적**: 지정 기간 내 디지털프린트 작업이 예정된 코일 목록을 확인
- **주요 흐름**:
  1. 작업 예정일자 범위(시작·종료)를 입력하고 필요 시 BOM번호·MO번호 조건을 추가 입력한다.
  2. 조회를 실행하면 A5 공정(디지털프린트)의 미완료 작업지시 코일 목록이 표시된다.
  3. 목록에서 BOM번호 링크를 통해 관련 코일 상세 화면(C106000060)으로 이동할 수 있다.
- **예외**: 검색 조건에 해당하는 작업지시가 없으면 목록이 비어 있음.

</details>

<details>
<summary>UC-02: 선택 코일의 상세 정보 확인</summary>

- **Actor**: 도장라인 작업 담당자
- **목적**: 목록에서 선택한 코일의 디지털프린트 이미지·품질 메시지·도장 설계 정보·생산이력을 확인
- **주요 흐름**:
  1. 작업지시 목록에서 코일 행을 선택한다.
  2. 해당 BOM에 등록된 디지털프린트 이미지가 이미지 패널에 표시된다.
  3. 고객사·용도 조건에 우선순위가 적용된 품질 메시지가 품질메시지 패널에 표시된다.
  4. 주문별 도장 설계 정보(고객사, 영업사원, 용도, TOP/BACK 도막 색상, 보호필름)가 제품정보 패널에 표시된다.
  5. 최근 생산완료 일자와 BOM번호가 작업이력 패널에 표시된다.
- **예외**: 등록된 디지털프린트 이미지가 없으면 이미지 패널에 "이미지가 없습니다." 메시지가 표시됨.

</details>

<details>
<summary>UC-03: 디지털프린트 이미지 확대 보기</summary>

- **Actor**: 도장라인 작업 담당자
- **목적**: 이미지 패널에 표시된 디지털프린트 이미지를 확대하여 상세 확인
- **주요 흐름**:
  1. 이미지 패널에서 이미지 셀을 선택한다.
  2. 전체 화면 오버레이로 이미지가 확대 표시된다.
  3. 마우스 휠로 확대/축소, 드래그로 이동이 가능하다.
  4. 오버레이 클릭 또는 ESC 키로 닫는다.
- **예외**: URL이 이미지 파일 형식(jpg, png 등)이 아닌 경우 오버레이가 열리지 않음.

</details>

- `TB_M17_INST_SEQ`와 `TB_C10_QLT_DSN_CMN`은 주문번호(ORD_NO)·주문행번(ORD_LN)으로 연결되며, A5 공정 작업지시에 대응하는 품질설계 정보를 조회한다.
- `TB_C10_QLT_DSN_CMN`과 `TB_C10_QLT_DSN_CCL_BOM`은 주문번호·주문행번으로 연결되어 BOM 단위 품질설계 상세를 제공한다.
- `TB_C10_CLR_MPR`은 BOM번호를 기준으로 고객사·용도 조합에 우선순위를 부여하여 품질 메시지를 결정한다.
- `TB_C10_DGT_PRT_IMG`는 BOM번호 앞 5자리를 기준으로 최신 등록 이미지를 제공한다.
- `TB_M47_PRD_ACT_CMN`은 주문번호·주문행번으로 최근 생산완료 일자를 집계한다.
- `VI_M00_CODE_ACCESS` 뷰는 품명코드·고객사코드·용도코드를 한국어 명칭으로 변환한다.

## 11. 특이사항 및 주의사항

### 1. 품질 메시지 우선순위 결정 로직
품질 메시지(`TB_C10_CLR_MPR`)는 동일 BOM에 대해 고객사(CUS_CD)·용도(ORD_USG_CD) 조합별로 여러 건이 등록될 수 있다. ① 고객사·용도 완전 일치 → ② 고객사 일치·용도 와일드카드 → ③ 고객사 와일드카드·용도 일치 → ④ 고객사·용도 모두 와일드카드 순으로 우선순위가 적용되어 가장 적합한 품질 메시지 1건이 표시된다.

### 2. 디지털프린트 이미지 조회 기준
이미지는 `TB_C10_DGT_PRT_IMG` 테이블에서 BOM번호 앞 5자리(`DGT_PRT_IMG_NO`의 앞 5자리)와 제품사양구분(`PRD_SPC_TP = '5'`) 조건으로 최신 등록 이미지 1건을 가져온다. BOM번호 전체가 아닌 앞 5자리 기준이므로 동일 계열 BOM들이 같은 이미지를 공유할 수 있다.

### 3. 조회 대상 조건 (미완료 작업지시만 표시)
작업지시 목록은 `TB_M17_INST_SEQ`에서 `WK_END_DH IS NULL`(작업 미완료) 조건을 적용한다. 동일 MO·BOM 조합에 여러 작업지시가 있을 경우 가장 이른 `WK_STR_SCH_DH` 기준 1건만 표시(`ROW_NUMBER()` 사용)한다.

### 4. 다중 스키마 참조
단일 화면에서 `MESAPUSER`(작업지시·생산실적), `C10APUSER`(품질설계·이미지), `M00APUSER`(공통코드), `M90APUSER`(사원정보) 등 4개 스키마를 참조한다. 각 세부 조회는 행 선택 시 개별 AJAX 호출로 분리 실행되며, 메인 목록 조회와 트랜잭션을 공유하지 않는다.

### 5. 이미지 오버레이 뷰어
선택 코일의 디지털프린트 이미지 셀을 클릭하면 JavaScript로 구현된 이미지 오버레이 뷰어가 활성화된다. 마우스 휠 확대/축소(0.2~5배), 드래그 이동, ESC 키·오버레이 클릭 닫기 기능을 제공하며 서버 요청 없이 클라이언트 측에서만 동작한다.
