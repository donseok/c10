## 2. 시스템 목적

C104000010은 냉연 제품의 품질설계의뢰 현황을 조회하는 화면이다. 생산 현장에서 접수된 주문 건에 대해 품질설계가 어떤 상태에 있는지(설계 대상 여부, 설계 진행 상태, 설계 완료 일시 등)를 한눈에 파악할 수 있도록 지원한다.

품질 담당자 및 생산 관리자는 이 화면을 통해 특정 기간·주문번호·품명·규격약호·주문용도·최종수요가·긴급재 여부·MO 전환 여부 등 다양한 조건으로 의뢰 현황을 검색하고, 조회된 결과를 엑셀로 내보낼 수 있다.

또한 목록에서 특정 주문 행을 선택하면 품질설계 상세 화면(C104000020)으로 이동하여 해당 주문의 상세 설계 내용을 연속적으로 확인할 수 있다. 이 화면은 데이터를 직접 변경하지 않는 순수 조회 전용 화면이다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 품질설계의뢰 현황 조회</summary>

- **Actor**: 품질 담당자, 생산 관리자
- **목적**: 특정 조건에 해당하는 주문의 품질설계의뢰 현황 목록을 확인한다
- **주요 흐름**:
  1. 설계의뢰일자(시작~종료), 주문번호, 품명, 규격약호, 주문용도, 최종수요가, 품질설계상태, 두께 범위, 긴급재 여부, MO 전환 여부, 품질설계유무 등 원하는 조건을 입력한다
  2. 입력된 날짜 범위의 유효성(시작일 ≤ 종료일, 필수 날짜 미입력 차단)을 확인한다
  3. 품질설계 공통 테이블(TB_C10_QLT_DSN_CMN)에서 조건에 맞는 주문 목록을 조회하여 표시한다
- **예외**: 시작일 또는 종료일 미입력 시 조회가 차단되며, 시작일이 종료일보다 늦을 경우 오류 안내가 표시된다

</details>

<details>
<summary>UC-02: 품질설계 상세 화면으로 이동</summary>

- **Actor**: 품질 담당자, 생산 관리자
- **목적**: 조회 목록에서 특정 주문 항목을 선택하여 해당 주문의 품질설계 상세 내용을 확인한다
- **주요 흐름**:
  1. 조회 목록에서 확인하려는 주문 행을 선택한다
  2. 주문번호, 주문행번, 품질설계유무 정보가 C104000020(품질설계 상세) 화면으로 전달된다
  3. C104000020 탭이 열리며 해당 주문의 품질설계 상세 내용을 확인할 수 있다
- **예외**: 해당 없음

</details>

<details>
<summary>UC-03: 조회 결과 엑셀 내보내기</summary>

  2. 엑셀출력을 요청하면 서버에서 동일한 조회 결과를 엑셀 형식으로 생성하여 다운로드한다

## 11. 특이사항 및 주의사항

### 1. 설계의뢰일자 필수 입력 및 유효성 검증
조회 시 설계의뢰일자(시작일, 종료일) 두 필드 모두 반드시 입력되어야 하며, 시작일이 종료일을 초과할 경우 조회가 차단된다. 주문번호가 입력된 경우 날짜 범위 조건은 자동으로 전체 범위(1900-01-01 ~ 3000-12-31)로 확장되어 주문번호 우선 검색이 가능하다.

### 2. 다중 코드 변환 서브쿼리 구조
조회 쿼리에서 주문용도, 품명, 최종수요가, 재질코드, 제품유형, 도금량, 표면처리코드, 보호필름코드, MO전환여부 등 다수의 코드 컬럼을 M00APUSER.VI_M00_CODE_ACCESS 공통 코드 뷰에 대한 서브쿼리로 코드값과 명칭을 결합하여 표시한다. 도금량(GW_ASG_CD)과 표면처리코드(ORD_SUR_HND_CD)는 품명코드(PRD_NM_CD)에 따라 조회 카테고리 그룹이 동적으로 달라지는 DECODE 분기 로직이 적용된다.

### 3. 화면 초기 로드 시 자동 조회 및 품질설계대상 고정 필터
화면이 처음 로드될 때 품질설계유무(QLT_DSN_YN=Y) 조건을 고정 파라미터로 설정하여 자동 조회가 실행된다. 이를 통해 화면 진입과 동시에 품질설계 대상 주문 목록을 즉시 확인할 수 있다. 사용자는 이후 품질설계유무 조건을 변경하여 비대상 주문도 조회할 수 있다.

### 4. C104000020 상세 화면 연동
목록의 특정 주문 행을 선택하면 주문번호, 주문행번, 품질설계유무 세 가지 파라미터가 C104000020(품질설계 상세) 화면으로 전달된다. C104000020은 탭 형태로 열리며, 현황 조회에서 상세 설계 내용까지 연속 탐색이 가능하도록 지원한다.
