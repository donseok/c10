## 2. 시스템 목적

C107000040은 품질설계 확정 내역을 다양한 조건으로 검색하고 결과를 조회하는 화면이다. 품질 담당자는 설계확정일자 범위를 기준으로, 품명·재질·도금량·제품유형·수지·엠보스·조도·스팽글·후처리·제품폭·압연 Set 등 세분화된 제품 사양 조건을 복합적으로 지정하여 원하는 주문의 품질설계결과를 빠르게 검색할 수 있다.

조회된 결과 목록에는 주문번호, 주문행번, 품명, 제품유형, 최종수요가, 두께, 폭, 길이, 압연 Set, 재질코드, 도금량, 설계확정일시 등 설계결과 확인에 필요한 핵심 정보가 포함된다. 담당자는 이 화면에서 특정 주문 항목을 선택하여 품질설계 상세 화면(C104000020)으로 이동해 상세 설계 내용을 연속적으로 확인할 수 있다.

이 화면은 데이터를 직접 변경하지 않는 순수 조회 전용 화면으로, 품질설계 결과에 대한 검색 및 탐색 기능만 제공한다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 품질설계결과 검색 조회</summary>

- **Actor**: 품질 담당자, 생산 관리자
- **목적**: 설계확정일자 범위 및 제품 사양 조건으로 품질설계 확정 내역 목록을 검색하여 확인한다
- **주요 흐름**:
  1. 설계확정일자(시작~종료, 필수), 품명, 재질, 도금량, 제품유형, 수지, 엠보스, 조도, 스팽글, 후처리, 압연 Set 범위, 제품폭 범위, 등록자 등 원하는 조건을 입력한다
  2. 설계확정일자 필수 입력 여부 및 시작일 ≤ 종료일 유효성을 확인한다
  3. 품질설계 공통 테이블(TB_C10_QLT_DSN_CMN)과 제조 테이블(TB_C10_QLT_DSN_MNF)을 조인하여 조건에 맞는 설계 확정 목록을 조회하여 표시한다
- **예외**: 시작일 또는 종료일 미입력 시 조회가 차단되며, 시작일이 종료일보다 늦을 경우 오류 안내가 표시된다

</details>

<details>
<summary>UC-02: 도금량 콤보 동적 로드</summary>

- **Actor**: 품질 담당자, 생산 관리자
- **목적**: 품명 선택에 따라 해당 품명에 적합한 도금량 코드 목록만 동적으로 제공하여 검색 조건 입력 오류를 방지한다
- **주요 흐름**:
  1. 품명 콤보에서 제품 분류를 선택한다
  2. 선택한 품명 코드(G/3/J/6 → SG0000, L/4 → SL0000, E/2 → SE0000)에 따라 해당 카테고리의 도금량 코드 목록을 공통코드(VI_M00_CODE_ACCESS)에서 로드한다
  3. 갱신된 도금량 목록에서 원하는 도금량을 선택하여 검색 조건에 포함한다
- **예외**: 품명 선택값이 도금량 카테고리 매핑에 해당하지 않을 경우 도금량 콤보를 초기화(비움)한다

</details>

<details>
<summary>UC-03: 품질설계 상세 화면으로 이동</summary>

- **Actor**: 품질 담당자, 생산 관리자
- **목적**: 조회 목록에서 특정 주문 항목을 선택하여 해당 주문의 품질설계 상세 내용을 확인한다

  1. 조회 결과 목록에서 확인하려는 주문 행을 선택한다

  3. C104000020 탭이 열리며 해당 주문의 품질설계 상세 내용을 확인할 수 있다
- **예외**: 해당 없음

## 11. 특이사항 및 주의사항

### 1. 설계확정일자 필수 입력 및 범위 검증

조회 시 설계확정일자 시작~종료가 반드시 입력되어야 하며, 시작일이 종료일보다 늦으면 조회가 차단된다. 화면 초기 로드 시 시작일은 전일(-1일), 종료일은 당일로 자동 설정되어 기본 조회가 즉시 실행된다.

### 2. 품명-도금량 연동 콤보 (동적 카테고리 변환)

도금량 콤보는 품명 선택값에 따라 로드할 공통코드 카테고리가 동적으로 변환된다 (G/3/J/6 → SG0000, L/4 → SL0000, E/2 → SE0000). 품명이 해당 카테고리에 속하지 않으면 도금량 콤보가 초기화된다. 이로 인해 품명과 도금량 조합의 검색 오류를 방지한다.

### 3. 다중 코드 서브쿼리 기반 복합 조회

SELECT 쿼리는 VI_M00_CODE_ACCESS에 대해 6개 이상의 서브쿼리를 수행하여 코드 필드(품명, 도금량, 재질, 엠보스, 조도, 스팽글, 후처리 등)의 명칭을 변환한다. 복합 조회 조건(15개 이상 파라미터)과 서브쿼리가 겹쳐 쿼리 복잡도가 높으며, 인덱스 및 실행계획 점검이 필요하다.

### 4. C104000020 화면 연동 (행 더블클릭 네비게이션)

조회 결과 목록에서 행을 더블클릭하면 주문번호(ORD_NO)와 주문행번(ORD_LN)을 파라미터로 C104000020(품질설계 상세) 탭을 동적으로 열어 연속 탐색을 지원한다. 이 화면은 검색 결과 탐색 허브로 활용된다.
