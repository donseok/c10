## 2. 시스템 목적

이 시스템은 MES C10 모듈에서 사용하는 **자재 마스터(Material Code)** 정보를 조회하는 화면이다. 자재코드(MTL_CD)는 생산 지시, 코일 추적, 공정 관리 등 MES 전반의 핵심 키로 사용되며, 해당 화면은 등록된 자재의 품명·재질·도금량·포장 방법 등 규격 속성과 반제품 공정 구성을 담당자가 통합 확인할 수 있도록 지원한다.

검색 조건으로 자재코드 직접 입력, 품명코드·제품형태·재질코드·도금량코드·CCL BOM 번호 등의 속성 조합 필터를 제공하며, 마스터 그리드에서 특정 자재를 선택하면 해당 자재의 반제품 공정 순서 및 구성 정보가 하단 상세 그리드에 자동으로 표시된다.

이 화면은 **순수 조회 전용** 서비스로, 데이터 입력·수정·삭제 기능은 포함되지 않는다. 코드 관리 담당자 및 생산 기술 담당자가 자재 속성과 반제품 공정 구성을 확인하는 용도로 사용한다.

## 7. 주요 유즈케이스

<details>
<summary>UC-01: 자재코드로 자재 마스터 조회</summary>

- **Actor**: 코드 관리 담당자, 생산 기술 담당자
- **목적**: 특정 자재코드에 해당하는 자재의 규격 속성 정보를 확인
- **주요 흐름**:
  1. 자재코드(Material Code)를 직접 입력한다
  2. 조회 요청을 실행하면 자재 마스터 목록 그리드에 해당 자재가 표시된다
  3. 자재유형, 품명, 제품형태, 재질코드, 도금량지정코드, 표면조도, Spangle, 표면처리, CCL BOM 코드, 압연 Set 두께, 주문폭, 포장방법, 보호필름, 표준원가, 수신일시 등 속성을 확인한다
- **예외**: 자재코드와 품명·제품형태 중 최소 하나를 입력하지 않으면 조회가 실행되지 않음

</details>

<details>
<summary>UC-02: 품명/제품형태 조합으로 자재 목록 조회</summary>

- **Actor**: 코드 관리 담당자, 생산 기술 담당자
- **목적**: 특정 품명·제품형태 등 속성 조합에 해당하는 자재 목록 전체를 확인
- **주요 흐름**:
  1. 품명코드 및 제품형태 콤보에서 원하는 값을 선택한다 (품명 선택 시 도금량코드 옵션이 해당 품명군에 맞게 자동 변경됨)
  2. 필요 시 재질코드, 도금량코드, CCL BOM 번호를 추가 조건으로 입력한다
  3. 조회 실행 후 조건에 부합하는 자재 목록이 그리드에 표시된다
- **예외**: 품명코드·제품형태 모두 선택하지 않고 자재코드도 미입력 시 조회 불가

</details>

<details>
<summary>UC-03: 자재의 반제품 공정 구성 확인</summary>

- **Actor**: 생산 기술 담당자, 공정 관리 담당자
- **목적**: 선택한 자재에 연결된 반제품 공정 순서 및 구성 정보를 확인
- **주요 흐름**:
  1. 자재 목록 그리드에서 조회 대상 자재 행을 선택한다
  2. 하단 반제품 공정 목록 그리드에 해당 자재의 플랜트구분·공정순서·공정코드·반제품 Material Code·수신일시가 자동으로 표시된다
  3. 공정 순서를 확인하여 반제품 BOM 구성을 파악한다
- **예외**: 자재 목록에서 행을 선택하지 않으면 반제품 공정 목록이 갱신되지 않음

</details>

### 엔티티 목록

| 엔티티(테이블) | 설명 | 사용 유형 |
|----------------|------|----------|
| TB_C10_MTL_MST | 자재 마스터 정보 (Material Code별 규격 속성) | 조회 |
| TB_C10_MTL_SEM_PROD | 자재별 반제품 공정 구성 정보 | 조회 |
| VI_M00_CODE_ACCESS | 공통 코드 설명 뷰 (자재유형, 품명코드, 제품형태, 재질코드, 도금량코드, 공정코드 등 설명 변환) | 조회 |

### 엔티티 간 관계

- TB_C10_MTL_MST와 TB_C10_MTL_SEM_PROD는 자재코드(MTL_CD)로 연결되며, 하나의 자재에 여러 반제품 공정이 매핑될 수 있다.
- TB_C10_MTL_MST 및 TB_C10_MTL_SEM_PROD의 각 코드 필드는 VI_M00_CODE_ACCESS 뷰를 스칼라 서브쿼리로 참조하여 코드값 대신 설명 텍스트로 표시된다.
- 도금량코드(ORD_GW_ASG_CD)는 품명코드(PRD_NM_CD)에 따라 SG0000·SL0000·SE0000 세 가지 카테고리 중 하나로 분류되어 마스터 코드를 조회한다.

## 11. 특이사항 및 주의사항

### 1. 조회 필수 조건 — 자재코드 또는 품명·제품형태 중 하나 필수
자재 마스터 조회 시 자재코드(MTL_CD)를 직접 입력하거나, 품명코드(PRD_NM_CD) 또는 제품형태(PRD_SHP) 중 하나 이상을 선택해야 조회가 실행된다. 두 조건 모두 입력하지 않으면 경고 메시지가 표시되고 조회가 차단된다. 이는 조건 없는 전체 조회로 인한 과도한 데이터 반환을 방지하기 위한 업무 규칙이다.

### 2. 품명코드 선택에 따른 도금량코드 옵션 동적 변경
품명코드(PRD_NM_CD) 선택 시 도금량코드(ORD_GW_ASG_CD) 콤보 옵션이 품명군에 따라 세 가지 카테고리(G·K·H·Z·J·3·6 → SG0000 / L·M·4 → SL0000 / E·F·2 → SE0000)로 동적 전환된다. 품명코드에 속하지 않는 값이 선택되면 도금량코드 옵션이 전체 초기화된다. 이 로직은 화면 클라이언트에서 처리되므로 서버 조회 전에 유효한 조합만 선택 가능하도록 설계되어 있다.

### 3. 마스터-디테일 연동 — 자재 선택 시 반제품 공정 목록 자동 조회
자재 마스터 그리드(Grid_1)에서 행을 선택하면, 해당 자재코드를 키로 반제품 공정 목록(TB_C10_MTL_SEM_PROD)이 자동으로 조회되어 하단 Grid_2에 표시된다. 이를 통해 자재의 제조 공정 순서(플랜트구분·공정순서·공정코드·반제품 Material Code)를 별도 화면 이동 없이 즉시 확인할 수 있다.

### 4. 코드 설명 변환 — VI_M00_CODE_ACCESS 뷰 스칼라 서브쿼리 활용
자재유형, 품명코드, 제품형태, 재질코드, 도금량코드, 스팽글, 표면처리, 포장방법, 공정코드 등 다수의 코드 필드는 공통 마스터 코드 뷰(VI_M00_CODE_ACCESS)를 스칼라 서브쿼리로 참조하여 "코드값+설명" 형식으로 변환하여 표시된다. 마스터 코드 데이터에 해당 카테고리/코드가 존재하지 않는 경우 원본 코드값만 표시될 수 있다.
